# Robinson's (1947) one-half conjecture is true

What is in this repository:

- [lean/](lean/) - the Lean 4 formalization of Theorems 1.1 and 1.2 and the other claims of the paper, from the computer-checked Lemmas 4.8, 6.2, 6.4 and 7.6 and six published theorems. Its README lists what the proof takes as given and how to verify it.
- [robinson-1947-one-half-conjecture/](robinson-1947-one-half-conjecture/) - the programs and data for the paper's computations, and how to run them.
