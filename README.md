# Robinson's (1947) one-half conjecture is true

What is in this repository:

- [lean/](lean/) - the Lean 4 formalization: Theorems 1.1 and 1.2 and the other claims of the paper, from the computer-checked Lemmas 4.8, 6.2, 6.4 and 7.6 and six published facts. Click it to see it, what it takes as given, and how to check it.
- [robinson-1947-one-half-conjecture/](robinson-1947-one-half-conjecture/) - the programs and data for the paper's computations. Click it to see them and how to run them.
